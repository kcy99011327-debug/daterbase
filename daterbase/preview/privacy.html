Daterbase 개인정보처리방침

English · Daterbase 소개 / About

시행일: 2026년 10월 18일

1. 어떤 앱인가요

Daterbase는 플래너 · 커미션 관리 · 기록 · 가계부를 한곳에서 쓰는 개인용 앱이에요. 개발자가 운영하는 서버는 없고, 모든 데이터는 사용자의 기기(또는 사용자가 직접 연결한 본인 소유의 Supabase 프로젝트)에만 저장돼요.

2. 구글 캘린더 데이터

  • 사용자가 "구글 계정 연결"을 눌러 허락한 경우에만, 구글 캘린더 일정을 읽고 쓰기 위해 Google Calendar API(https://www.googleapis.com/auth/calendar)를 사용해요.
  • 가져온 일정은 앱의 타임테이블에 보여 주고, 앱에서 만든 일정을 사용자의 구글 캘린더에 반영하는 데에만 써요.
  • 구글 계정 정보와 일정 데이터는 사용자의 기기 안에만 저장되며, 개발자나 제3자에게 전송 · 판매 · 공유하지 않아요. 광고나 분석에 쓰지 않아요.
  • Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

3. 그 밖의 데이터

  • 일정 · 할 일 · 기록 · 이미지 등은 사용자의 기기에 저장돼요. 동기화를 켜면 사용자가 직접 만든 Supabase 프로젝트에만 저장돼요.
  • 개발자는 사용자의 데이터에 접근할 수 없어요.
  • 구글 캘린더를 처음 연결하면, 연결한 인원수를 세기 위해 그 기기의 무작위 번호 하나만 개발자의 집계 시트로 보내요. 이메일·구글 계정·일정 등 다른 정보는 보내지 않아요.

4. 연결 해제와 삭제

  • 앱 설정 › 구글 캘린더 연동에서 "연결 해제"를 누르면 기기에 저장된 구글 로그인 정보가 지워져요.
  • 구글 계정의 서드 파티 액세스 관리에서도 언제든 권한을 취소할 수 있어요.
  • 앱 데이터는 앱 설정에서 지우거나, 앱을 삭제하면 기기에서 지워져요.

5. 문의

앱 안의 "사용 설명서 · 오류 문의" 또는 구글 동의 화면에 표시된 지원 이메일로 연락해 주세요.

Privacy Policy (English)

Effective: October 18, 2026

1. About the app

Daterbase is a personal app that combines a planner, commission (art request) management, records and a budget book. The developer runs no servers. All data is stored only on the user's device, or in a Supabase project that the user creates and owns.

2. Google Calendar data

  • Only when the user presses "Connect Google account" and grants permission, the app uses the Google Calendar API (https://www.googleapis.com/auth/calendar) to read and write the user's calendar events.
  • Events are used only to show them in the app's timetable and to reflect events the user creates in the app back to the user's own Google Calendar.
  • Google account information and calendar data are stored only on the user's device. They are never sent, sold or shared with the developer or any third party, and are not used for advertising or analytics.
  • Daterbase's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Other data

  • Schedules, to-dos, records and images are stored on the user's device. If sync is turned on, they are stored only in the user's own Supabase project.
  • The developer cannot access user data.
  • When Google Calendar is connected for the first time, the app sends only a random device identifier to the developer's counter sheet, to count how many devices have connected. No email address, Google account information or calendar data is sent.

4. Disconnecting and deleting

  • In Settings › Google Calendar, "Disconnect" removes the Google sign-in data stored on the device.
  • Access can be revoked at any time from Google Account › Third-party access.
  • App data can be deleted in the app settings, or by uninstalling the app.

5. Contact

Use "Help · Report a problem" inside the app, or the support email shown on the Google consent screen.
